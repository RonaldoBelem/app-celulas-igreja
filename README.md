# 🌐 WebView App

Este projeto é um aplicativo Android criado com **Android Studio** e **Gradle**, que utiliza o componente **WebView** para emular seu site diretamente dentro do app. O objetivo é gerar um APK compatível com qualquer celular Android site usado no app https://celulas-igreja.vercel.app/.

---

## 🚀 Funcionalidades

- Acessa seu site diretamente pelo app
- Interface simples e leve
- Compatível com qualquer dispositivo Android
- Geração fácil de APK via Gradle

---

## 🛠️ Tecnologias

- Android Studio
- Kotlin 
- Gradle
- WebView
